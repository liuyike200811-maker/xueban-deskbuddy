# ESP32-S3 N16R8 接线与开发

本表按常见 ESP32-S3-WROOM-1 N16R8 排针规划。N16R8 说明存储配置，不说明开发板 PCB 的版本、排针顺序或电源电路。接线按排针丝印 IO4/4 等编号认脚，不按从 USB 口数第几针。若需标出物理位置，拍一张板子正面全图，需看清 USB 口、两侧排针和模块金属罩丝印。

## GPIO 分配

| 模块 | 信号 | ESP32-S3 | 供电及说明 |
|---|---|---|---|
| TTP223（当前固件不用） | OUT / SIG | GPIO4 | 可保持现有接线，固件不读取 |
| 对话按钮 | 常开触点 | GPIO18 / GND | GPIO18 内部上拉，单按切换对话，开机默认开启 |
| 板载 RGB | 板内走线 | GPIO48（按当前板型配置） | 绿色心跳为开启，黄色慢呼吸为关闭；无需外接 |
| SHT30 | SDA / SCL | GPIO8 / GPIO9 | 3V3；先扫 0x44 / 0x45，确认板载上拉接 3V3；没有则各加约 4.7 kΩ |
| HC-SR04 | TRIG / ECHO | GPIO5 / GPIO6 | 5V；TRIG 发 ≥10 µs 脉冲，ECHO 必须经分压；3.3V TRIG 如实物不识别，再用 AHCT 转成 5V |
| WS2812 | DIN | GPIO7 | 5V；GPIO7 → 5V 供电的 74AHCT125 → 330 Ω → 灯带 DIN，按箭头找输入端 |
| INMP441 | SCK / WS / SD | GPIO10 / GPIO11 / GPIO12 | 3V3，L/R 接 GND 选左声道；SD 是麦克风数据输出 |
| MAX98357A | BCLK / LRC / DIN | GPIO15 / GPIO16 / GPIO17 | VIN 和 SD 同接外设稳压 5V；GAIN 留空；扬声器只接 SPK+ 和 SPK− |
| 180° 舵机（暂未接入） | PWM | 待分配 | 原 GPIO16 已用于功放 |
| 0.96 英寸 OLED（疑似 JMD0.96D-1） | SDA / SCL | GPIO8 / GPIO9 | VCC 接板上 3V3，GND 共地；I²C 地址先扫描确认（优先检查 0x3C），驱动先按 SSD1306 128×64 测试 |
| 锂电池组 | — | 不接 GPIO | 先核对节数、额定电压、保护板、极性和放电能力 |

避开 GPIO0/3/45/46 启动绑带脚、GPIO19/20 原生 USB、GPIO26–37 存储相关或未引出引脚（尤其是 GPIO35–37 已用于 N16R8 的 OPI PSRAM），并保留 GPIO43/44 给板载 UART。音频输入和输出各用一组独立的 I²S 引脚；首版先分开验证，再考虑同时运行。

## 供电与接线要点

- 调试时电脑 USB 只给开发板供电；TTP223、SHT30 和 INMP441 接板上 3V3。HC-SR04、灯带、功放和符合电压规格的舵机接独立稳压电源，所有 GND 共地。外设电源正极不与开发板 USB 的 5V 并接。舵机、灯带和功放供电各从电源分支，别用开发板排针转供；电源按实际灯珠数、功放和舵机峰值选。
- ECHO 接法：模块 ECHO → 两颗 1 kΩ 串联 → GPIO6；GPIO6 → 三颗 1 kΩ 串联 → GND。5V 高电平分压后约 3.0V。先接分压再上电。
- 74AHCT125 的使用通道 /OE 接地，VCC 与 GND 旁放 0.1 µF 去耦；未用通道禁用并固定输入电平。330 Ω 靠近第一颗灯珠，灯带入口 5V 与 GND 并 500–1000 µF（≥6.3V，注意极性）；先点少量灯珠、用低亮度。灯带断电时不要向 DIN 送数据。
- 3W 表示扬声器的功率规格，还要核对阻抗。若为 4 Ω，MAX98357A 可按低音量试机；扬声器两根线都不要接系统 GND。INMP441 只计算短窗口相对音量，播报时暂停噪声判定，避免设备自己触发提醒。
- 舵机先不带机构测试中位，再装叶片、逐步扩大角度，避免顶死；3.3V PWM 兼容性按实物确认。
- 电池留到台式版跑通后。不能仅凭示意图确定电池接法。若确认为受保护的 1S、满充 4.2V 锂电池，可选匹配充电电流的 1S 电源路径充电模块，再用满足峰值负载的 5V 升压供系统；BQ24074 只是参考，OUT 不是 5V。电池不直连 5V/3V3 排针。若是多节组，按其电压和配套保护/充电规格重做方案。

## Arduino 配置

选 ESP32S3 Dev Module；Flash Size 16MB、Flash Mode QIO 80MHz、PSRAM OPI、Partition Scheme 16M Flash (3MB APP/9.9MB FATFS)。从原生 USB 用 TinyUSB 做应用串口时，USB Mode 选 USB-OTG (TinyUSB)，USB CDC On Boot 启用。首次上传时若旧应用不支持自动进入下载模式，按住 BOOT、轻按 RESET/EN、松开 BOOT，再重新确认 COM 号后上传。

CLI（在普通 PowerShell 的项目根目录运行，仅编译）：

~~~powershell
$cli = 'C:\Users\Tutul\AppData\Local\Programs\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe'
& $cli compile --fqbn esp32:esp32:esp32s3:USBMode=default,CDCOnBoot=cdc,FlashSize=16M,FlashMode=qio,PSRAM=opi,PartitionScheme=app3M_fat9M_16MB tools\SerialSmoke
~~~

## 开发顺序

1. 裸板：编译并在获准后上传串口草图。复位后重新选 COM，115200 看到每秒一行，后续再读 Flash/PSRAM 实际大小。
2. 最小演示：先接 TTP223，然后接带电平转换的 WS2812。用 millis() 驱动“待机 → 专注 ↔ 暂停 → 完成”，用短倒计时验证，演示默认 25 分钟。ESP32 提供局域网页，显示剩余时间、调整时长和查看完成记录；完成时灯光反馈。先用本地网页，无需云服务。
3. 分别接 SHT30、HC-SR04。SHT30 只展示温湿度；HC-SR04 先在真实桌椅上标定，用连续有效读数判断在座/离座，偶发超时视为未知。超声波只能测前方物体距离，不能识别身份或走神。
4. 依次接 INMP441、MAX98357A 和舵机：先读相对音量，再播放短 PCM 语音，最后验证动作；先单模块后联调。Arduino 自带 Wire、ESP_I2S、LEDC、WiFi/WebServer；灯带可先少量验证，再按需要加 Adafruit NeoPixel 库。
5. 最后接入确认型号的电池供电和 OLED；验证所有外设同时工作时无掉压复位。

本机验证：Arduino CLI 1.5.1、Espressif Arduino core 3.3.11、esptool 5.3.1 已安装。Windows 报告 COM13 已启动，USB VID/PID 为 303A:4001，Arduino CLI 能列出端口。上述 N16R8 配置在普通 Windows 环境编译通过（应用 356424 字节）。尚未上传、读取板上固件或测试外设。
