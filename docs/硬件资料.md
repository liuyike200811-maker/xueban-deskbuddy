# 中文硬件资料

首选下面的中文资料。没有核实到中文完整规格书的模块，使用厂商中文产品页或中文模块教程；接 ESP32-S3 时以[本项目接线表](接线与开发.md)为准。OLED 暂不纳入。

| 模块 | 中文资料 | 本项目接线要点 |
|---|---|---|
| ESP32-S3 N16R8 | [乐鑫中文技术规格书（本地 PDF）](中文资料/ESP32-S3-WROOM-1-乐鑫技术规格书.pdf) · [乐鑫 DevKitC-1 中文指南](https://docs.espressif.com/projects/esp-dev-kits/zh_CN/latest/esp32s3/esp32-s3-devkitc-1/index.html) | 16 MB Flash、8 MB OPI PSRAM；排针以实际开发板丝印为准 |
| TTP223 触摸 | [科易互动中文教程](https://www.keyesrobot.cn/projects/KE3086-KE3087-KE3088-KE3086S-KE3087S-KE3088S/zh-cn/latest/docs/%E9%A1%B9%E7%9B%AE%E6%95%99%E7%A8%8B/%E9%A1%B9%E7%9B%AE%E6%95%99%E7%A8%8B.html)（页内搜 TTP223） | 3V3、GND、OUT 接 GPIO4；确认触摸和松开时电平变化 |
| HC-SR04 超声波 | [立创中文模块教程](https://wiki.lckfb.com/zh-hans/fpga-ljpi/module/sensor/hcsr04.html) | 标准 5V 版的 Echo 先分压再接 GPIO6 |
| SHT30 温湿度 | [Sensirion 中文产品页](https://sensirion.com/cn/products/catalog/SHT30-DIS-B) | 3V3；SDA/SCL 接 GPIO8/9，扫描 0x44 或 0x45 |
| INMP441 麦克风 | [TDK 中文产品页](https://product.tdk.cn/zh/search/sw_piezo/mic/mems-mic/info?part_no=INMP441) | 3V3；SCK/WS/SD 接 GPIO10/11/12，L/R 接地选择左声道 |
| WS2812 灯带 | 未核实到可靠的中文完整规格书 | 独立 5V，共地；GPIO7 经 74AHCT125 和串联电阻接 DIN，认准输入端箭头 |
| MAX98357A + 3W 喇叭 | [ADI 中文产品页](https://www.analog.com/cn/products/max98357a.html) | BCLK/LRC/DIN 接 GPIO13/14/15，喇叭只跨接 SPK+/SPK−；阻抗以实物标签为准 |
| 180° 舵机 | [立创 SG90 中文参考教程](https://wiki.lckfb.com/zh-hans/linux-docs/linux-driver-related-subsystems/pwm-subsystem/sg90-servo-drive-experiment.html) | SG90 仅作参考；确认实物型号和电压后独立供电，PWM 用 GPIO16，先试中位 |
| 锂电池组 | [德州仪器 BQ24074 中文数据手册（本地 PDF）](中文资料/BQ24074-德州仪器数据手册.pdf) | 这是单节锂电充电方案参考。手头电池节数、极性和保护未确认，暂不接 |
