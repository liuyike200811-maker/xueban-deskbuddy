# OLED 桌宠

参考 [Clawd on Desk 的像素螃蟹和状态动效](https://github.com/rullerzhou-afk/clawd-on-desk#themes)，在 128×64 单色 OLED 上重画低矮壳、钳子和短腿，不使用上游贴图。

- 待机：居中，随机眨眼、左右看或举钳。
- 对话：听时抬钳，思考时眼睛侧看、跳出思考点，回复时嘴和钳子活动。
- 播放：音乐、提示音和语音回复时桌宠小幅跳跃；本地音频播放时待机会换成笑眼。上方的计时显示不跟着跳。
- 计时：桌宠留在下方蓝色区，上方黄色区居中显示剩余时间和逐渐缩短的进度线。休息超时在黄色区显示小提示符。
- 屏幕不显示状态文字或 Wi-Fi 字样。灯带仍用现有状态灯效。
