# DeskBuddy 中文语音最小对照

保留板端直连百炼作为基线。Zipformer 先作为 Windows 上的只转写对照，不接真实计时、点歌或播报。不用现有固定 5 秒的 `/voice` 测端到端实时延迟。

1. 从 INMP441 保存完整的 16 kHz 单声道 PCM（含开头和结尾各一小段静音）。优先保留板端降噪后的 PCM；出现漏字再同批保存降噪前的 PCM。现有串口终端只能看文本事件，不能替代 PCM 采集。
2. 三句各录三次：「专注二十五分钟」「休息五分钟」「取消倒计时」。近讲正常、说到一半停约 0.7 秒、实际背景噪声下稍远说，各一轮。标准动作分别为 focus/1500 秒、rest/300 秒、stop。
3. 第一遍把每段完整音频按原速分块分别送给两种转写器，使用同一条音频终点，记录关键字、数字、单位和最后一块送出到最终文本的时间。第二遍保留各自的端点判断，比较是否提前结束、是否漏开头、说完到最终文本的时间。保留每条样本结果，不用九条样本推断总体准确率。
4. 用相同最终文本离线核对「模式 / 秒数 / 停止动作」。若转写正确但动作错误，优先查板端规则和模型工具调用。到板的首段回复音频另记，不能混作 ASR 延迟。

判断次序：录音本身缺字查采集；录音完整而云端提前结束查断句；同终点的完整音频转写错才比较 ASR；转写对而动作错查指令执行。播报中没法插话另测，现固件在回应或提醒时会上送静音。

灯光沿用当前状态映射：监听为绿色呼吸，听、处理、播报为连续彩色跑马，语音错误或掉网为红色双闪。切换识别器也沿用同一状态映射。
